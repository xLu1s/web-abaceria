# La Abacería de San Lorenzo · Alcoy

Demo estática en Astro del bar restaurante **La Abacería de San Lorenzo**, en el número 39 de la calle San Lorenzo (C. Sant Llorenç), 03801 Alcoi.

Sitio publicado: [https://xlu1s.github.io/web-abaceria/](https://xlu1s.github.io/web-abaceria/)

No es la web oficial. A 31 de octubre de 2026 el local no tenía sitio propio. Los datos salen de fuentes públicas (Instagram, Google Maps, RAE y prensa local). No se ha contactado con el negocio.

## Por confirmar

- Logo en SVG (ahora se usa el PNG del perfil de Instagram; el lettering no se reconstruye con fuentes)
- Horario oficial: la bio de Instagram y Google Maps no coinciden. El cierre de los jueves no está publicado
- Carta y precios (la página `/carta/` es orientativa, sin precios)
- Alérgenos
- Email y canal de reservas distinto del teléfono 746 05 11 55
- Venta de producto para llevar, capacidad, terraza y qué hay al final de la escalera
- Vermut de grifo o no, y el detalle de desayunos, vinos y conservas
- Archivos originales de ilustraciones y sus derechos
- Titular, NIF y web oficial
- Si quieren la web también en valenciano

## Desarrollo

```bash
npm install
npm run dev
```

La base es `/web-abaceria`. En local se abre en `http://localhost:4321/web-abaceria/`.
